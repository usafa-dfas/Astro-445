What is happening

The questionCan you tune an LQR that meets all four requirements on the nonlinear, torque-limited satellite?

—

    New to this? Key terms
    Slew
    A deliberate change of attitude, here a turn in pitch to a new commanded angle.
    Error quaternion
    The rotation from where the satellite is to where it should be. Feeding back its vector part makes the regulator steer to the command instead of to zero.
    Integral action
    An extra state that adds up the error over time, so a constant disturbance cannot leave a steady offset.
    Windup
    The integrator piling up while the error is large, during a slew or while the wheel is saturated, and then having to be unwound by overshooting.
    Gating
    Letting the integrator run only while the error is small.
    Command shaping
    Ramping the commanded angle instead of stepping it, so the error, and the torque it asks for, never gets large.
    Saturation
    The wheel asked for more torque than it can give; it gives its maximum and the linear design no longer describes what happens.

    Checks worth running

      Model

      Design model (one axis)
      x = [z, θ, θ̇, h] (z and h when chosen),  ż = θ,  Ipθ̈ = u − kggθ,  ḣ = −u
      Q = diag(1/(θmaxTi)², 1/θmax², 1/ωmax², 1/hmax²),  R = 1/umaxR²
      Controller, as in the lab script
      e = 2 sin((θ − θc)/2),  u = sat(−K[z, e, θ̇ − θ̇c, h]),  ż = e while |e| < gate
      θc ramps to the slew over the ramp time, or steps
      Three effects worth predicting
      offset under gd: θss = gd/(k1 + kgg);  wheel filling: ḣ = gd
      d/dt(Ipθ̇ + h) = gd − kggθ: the controller cannot change the total momentum
      Error quaternion
      δq0 = qc0q0 + qcTq,  δq = qc0q − q0qc − qc×q; flip the sign when δq0 < 0

      The simulation integrates the lab script's equations with fixed-step RK4 instead of ode45, so its numbers differ from MATLAB's in the last digit or so. The three-axis gain uses the Lesson 34 nine-state model with the same Bryson limits (qmax = θmax/2). kgg = 3ωc²(Ir − Iy) = 3.52 × 10⁻⁵ N·m/rad. The Riccati equation is solved by the matrix sign function, polished by Newton steps.
